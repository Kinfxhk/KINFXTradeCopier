# Test matrix — collaborative source alpha

**Trading acceptance is not established. Start and Flatten must remain held for every external NinjaTrader account, including Simulator and Playback.** This is a source-collaboration project, not an installable trading release. Safety defects block later trading enablement; they do not block sharing disarmed source, tests and review tasks.

The public source starts from baseline SHA-256 `1def30ce3d522393a8daa0ebb829e7630ab6b9b2d66549d3ea5e6309436420c1`, with separate publication-hold edits. It is **not** the repair clones described below. [EVIDENCE.json](EVIDENCE.json) pins the observed public snapshot and historical source/candidate hashes. Any later source edit needs a new exact pin and matching results. This documentation audit executed no engine, native account, GUI or trading acceptance test.

## Read results by scope, not by headline totals

| Status | Meaning |
|---|---|
| **UNTESTED** | No execution evidence for that exact artifact/environment/scenario. Related fake tests do not fill the gap. |
| **KNOWN PRODUCT DEFECT** | A failed safety invariant on a pinned implementation. Provider reproduction is a separate question. |
| **HARNESS / ORACLE / POLICY MISMATCH** | Preserve the failure; investigate fixture validity, representation or an unadopted contract before attributing a product defect. |
| **SCOPED FIX — NOT INTEGRATED** | The named candidate passed named probes. It is not merged or accepted on public source. |
| **PURE SPEC / POLICY ONLY** | Model, validator or pure reducer evidence; not engine dispatch acceptance. |
| **PROVIDER UNKNOWN** | Real platform/provider behavior has not been accepted. |

Counts below are **invocations**, not unique branch coverage, account capacity, independent defects or safety certification. Repeats, permutations, detailed checks, hash pins and snapshots have different units and may overlap. No global PASS or coverage percentage is derived from them.

## Reporting a useful contribution

State the test ID, exact source/test SHA-256, command, environment, fake/reference boundary, expected invariant, actual result and retained failure classification. Add a minimal **synthetic** reproducer and negative control. Record whether any code was merged separately from candidate results. Redact paths and account identities; omit raw trading logs, credentials, vendor HTML and proprietary binaries. A known-defect assertion which verifies bad behavior and exits zero is a defect probe, not acceptance.
